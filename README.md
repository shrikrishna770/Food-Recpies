# Food Recipes

A **collaborative full-stack web application** for discovering, sharing, and managing food recipes. Built with a team, the project allows users to:

- Sign up and log in (including Google login)  
- Add, edit, or delete their own recipes  
- Browse public recipes in the community feed  
- Maintain a personal wishlist of favorite recipes  

This project emphasizes teamwork, full-stack development skills, and building user-friendly interfaces.

**Live Demo:** *[Food Recpies](https://foods-recipes-find.vercel.app/login)*

---

## Features

- User authentication (email/password & Google)  
- Add, edit, delete personal recipes  
- Mark recipes as public or private  
- Browse community feed of public recipes  
- Personal wishlist for favorite recipes  
- Calorie statistics dashboard  

---

## Tech Stack

- **Frontend:** React, Vite, Tailwind CSS  
- **Backend:** Node.js, Express, MongoDB, Firebase Admin  
- **Authentication:** JWT, Firebase  

---

## Getting Started

### Backend
```bash

```
### Frontend
